# Smoking and Health Analysis Dashboard

An interactive healthcare analytics dashboard developed using **Microsoft Power BI** to explore patient smoking patterns, health conditions, and key health indicators.

## Project Overview

This project analyzes patient-level data to help explore smoking habits, recorded health conditions, and health indicators such as cholesterol and blood pressure.

## Project Objectives

- Analyze overall patient health using key performance indicators (KPIs).
- Create calculated columns using DAX for Age Group and BP Risk Category.
- Analyze smoking patterns and health indicators.
- Explore patient demographics and health patterns across smoking exposure groups.

## Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- CSV dataset

4. Average Cigarettes Smoked Per Day by Smoking Status
5. Organ-wise Health Condition Distribution
6. Recorded Health Conditions by Smoking Exposure Group

## DAX Calculated Columns

- **Age Group:** 18–29, 30–44, 45–59, and 60+.
- **BP Risk Category:** Lower Range, Elevated, and High.
- **Smoking Exposure Group:** Categorizes estimated smoking duration into ranges.
